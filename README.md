# FB 廣告雷達

香港同行正在投放的 Facebook／Instagram 廣告參考看板。資料來自 Meta 廣告庫（Meta Ad Library），靜態網頁，部署在 GitHub Pages。

## 檔案

- `index.html`：看板（讀取 `data.json`）
- `data.json`：廣告資料。**要更新看板，只需要換這個檔案**

## 資料的限制

- 廣告庫只提供頁面名稱、標題、開始投放日期和廣告連結，**沒有完整文案、花費或曝光**。
- 判斷有沒有效，只能看「投放天數」：投得越久，通常越值得參考。
- 香港的商業廣告沒有官方 API，資料由 Claude 透過 Meta 廣告連接器查詢後寫入，**不會自動更新**。想更新就請 Claude 重新查一次。
- 「分類」是人手按頁面和標題歸類，只供篩選。
